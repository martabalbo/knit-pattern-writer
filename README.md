# knit-pattern-writer
Fill in a grid and get a written pattern for your double knitting project!

I'm trying to create a website where knitters can fill in a grid and get a written pattern for their double knitting or colorwork projects.

To do so, I built a basic HTML website that lets the user generate a grid with their chosen dimensions, creating a centered grid in the webpage using Javascript.

Then, the user can color the squares, by clicking on them to toggle the color on and off, to create their chosen design.

Finally, they can generate the written pattern using the appropriate button, and follow the instruction to create their personalized knitting project.
